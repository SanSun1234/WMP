# Wedding Invitation: Михаил и Полина

Премиальный адаптивный сайт электронного свадебного приглашения.

## Что внутри

- Hero-приглашение с анимацией появления.
- Обратный отсчёт до 5 сентября 2026.
- Блок пожеланий: дресс-код, подарки, музыка.
- Распорядок дня.
- Блок локации с быстрым переходом к карте.
- RSVP-форма с локальным сохранением ответа в браузере.
- Кнопка добавления события в календарь.
- Mobile-first адаптив и лёгкие scroll-анимации.

## Запуск

Откройте `index.html` в браузере или опубликуйте репозиторий через GitHub Pages.

## GitHub Pages

В настройках репозитория откройте `Settings -> Pages`, выберите ветку `main` и папку `/root`.
